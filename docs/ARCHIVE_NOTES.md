# 归档边界与已发现的版本差异

## 完整性

仅按文件内容 SHA-256 去除完全重复副本；文件名相同但内容不同则全部保留。主线目录保存研究步骤对应源码，其余版本使用“哈希前缀_原文件名”命名，避免同名覆盖。

`source_manifest.csv` 一行对应一个源脚本；`retained` 表示保留该原件内容，`exact_duplicate` 表示其内容与映射到的保留文件完全一致。`source_documents.json` 记录额外复制的原复现说明。源码未拼接、改编码或改行尾。

## 归档不代表已经可以一键复现

原脚本保留绝对路径、手工对象依赖和既有输入输出名称。按研究步骤重排目录不会自动修复这些依赖；历史目录中的不同脚本也不是一套可以直接顺序执行的流程。`code_requirements.csv` 记录了相关路径与输入位置，`dependency_inventory.csv` 是静态发现的依赖清单，不是锁定环境。

R/Python 静态检查仅检查能否解析，不执行模型、不访问数据库，不验证收敛或指标正确性。完整性结果见 `validation_summary.json`。

## 已具体发现的内容

1. [历史作图脚本](../90_history/manual_metric_adjustment/ff8fce61ed_%E7%BB%93%E6%9E%9C%E6%95%B4%E7%90%860509_%E5%87%BA%E5%9B%BE.R#L12) 对 JM 的 AUC/C-index 加 0.04，对部分其他结果加 0.07，并对部分 BS 减 0.08。这段原代码保留在 `90_history/manual_metric_adjustment`；不能作为模型重新计算指标的实现或性能证据。
2. 主线实例配置采用动态 28 个固定变量与 3 个轨迹；其他版本存在动态 25 个固定变量。归档不混用两套口径。
3. 主线 `01_stage_inputs.R` 还需要参考论文 DOCX；原 README 的“两个输入”未涵盖这一依赖。
4. 五折搜索是原流程的可选步骤，部分模型脚本还保留预设/写入的调参汇总值；复制这些代码不等于完成了新的交叉验证。
5. 模拟研究 JM 目录含多个实现和时间窗口设置；变量子集搜索与调试脚本在历史目录。这次未把这些版本认定为同一个最终实验。
