# 模拟研究的六个设计维度

这里的“六种变量”指六个**实验设计因素**，不是模型只有六个协变量。原结果整理代码按六列解析与分组：[数据整理.R，情景名解析](../01_simulation/06_figures/%E4%BB%A3%E7%A0%81/%E6%95%B0%E6%8D%AE%E6%95%B4%E7%90%86.R#L248)。

1. **样本量**：主要批量生成使用 500、1000；函数的默认值或试跑值不等于全部正式情景。
2. **删失率**：主要目标值为 30%、70%；生存生成脚本通过 `target_censor` 校准删失。
3. **变量数**：4 或 10，对应 `4V`、`10V`。
4. **相关强度**：low、mid、high。相关矩阵原设计使用低 0.05–0.3、中 0.3–0.7、高 0.7–0.9 的参数范围，见 [相关矩阵设计](../01_simulation/01_design/4_%E6%A8%A1%E6%8B%9F%E6%95%B0%E6%8D%AE_%E7%9B%B8%E5%85%B3%E7%B3%BB%E6%95%B0%E7%9F%A9%E9%98%B5.R#L31)。它们是生成参数范围，不是每份样本实际相关系数的保证；正定修正及具体版本也可能改变实现。
5. **相关结构/相关特性**：`INTER`、`BTW`。原生存生成脚本将高影响变量间相关与高影响变量/弱效应变量相关的设定区分开，见 [系数设定](../01_simulation/02_generation/training/10v_3c/4_%E6%A8%A1%E6%8B%9F%E6%95%B0%E6%8D%AE2_%E7%94%9F%E5%AD%98%E6%95%B0%E6%8D%AE.R#L52)。不同版本中也通过改变系数或读取不同协方差矩阵实现，不应只根据名称认为机制完全相同。特别是 [4V 补充生成脚本](../01_simulation/02_generation/paired_test/4_%E8%A1%A5%E5%85%85_%E6%A8%A1%E6%8B%9F%E6%95%B0%E6%8D%AE_4V.R#L202) 注明该版本无协方差矩阵、通过弱化 V4 系数构造 BTW。
6. **潜类别数**：1 或 3，对应 `1c`、`3c`，用于表达轨迹/效应的群体异质性；[三类别生成实现](../01_simulation/02_generation/training/10v_3c/4_%E6%A8%A1%E6%8B%9F%E6%95%B0%E6%8D%AE1_%E6%95%B0%E6%8D%AE%E7%94%9F%E6%88%90.R#L26) 使用不同类别固定效应及随机效应矩阵。

主线保留 `4v_1c`、`10v_1c`、`10v_3c` 三组生成源码。六因素并不意味着所有水平都做了完全交叉：4V 情景与后来补充的 BTW 版本存在差异，因此这里不把理论组合数写成已完成实验数。

## 数据生成顺序

- `01_design`：相关与随机效应结构。
- `02_generation/training/*/4_模拟数据1_数据生成*.R`：生成纵向协变量和轨迹；典型设置为 5 次观测、时间在 0–1 内。
- 同目录的 `4_模拟数据2_生存数据*.R`：生成生存时间、删失时间、观测时间和事件状态。
- 同目录的 `4_模拟数据3_生成Y*.R`：整合/整理最终长格式数据，保留原命名与处理顺序。
- `03_preprocessing`：整理静态模型的单时间点输入。
- `02_generation/paired_test`：另一组种子生成的配对测试数据版本。

## 四模型与评价

Cox、RSF 属于静态比较；JM、RSFLC 使用纵向信息。模型脚本计算并导出 AUC、BS、C-index，`05_evaluation` 整理结果，`06_figures` 作图。归档未统一不同版本的指标实现，也未证明各版本时间窗口完全一致；查阅时要同时核对评价时点、样本人群与输入轨迹截断。
