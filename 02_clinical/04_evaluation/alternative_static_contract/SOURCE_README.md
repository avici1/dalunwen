# RSF、Cox、RSFLC与JM统一评价口径

## 表5-4A静态模型

- 人群：仅使用同时具有基线资料和ICU第1天截面的患者；group=1训练，group=2独立验证。
- 终点：入ICU后28天全因死亡；时间原点为ICU入科时刻。
- 训练集C-index：RSF采用OOB值，只用于描述模型内部表现。
- 主比较：共同验证集的C-index、累积/动态AUC(28)、IPCW-Brier(28)、IPCW-IBS(0–28)。
- 评价点必须是恰好28天；不得用27.9999天替代后仍称为28天。
- IBS必须使用每位患者在完整评价网格上的风险曲线，不能复制单一28天风险。

## RSFLC与JM动态模型

- 预先固定landmark为第5天（与论文现有动态任务一致），避免根据验证集结果挑选landmark。
- 共同风险集：第5天仍存活且仍有随访，即 `T > 5`；两个模型必须使用完全相同的患者ID。
- 信息截断：只能使用第5天及以前可获得的纵向历史与基线信息。
- 预测窗：从第5天预测至第28天，统一报告AUC(5,28)、Brier(5,28)、IBS(5–28)。
- 条件风险统一定义为 `P(T <= t | T > 5, history <= 5)`，风险越大表示死亡风险越高。
- IPCW删失模型、时间网格、缺失值规则和bootstrap/置信区间设置必须一致。

## 结果报告原则

主模型比较只使用独立验证集。训练集OOB、表观值和交叉验证值不是同一种估计量，必须清楚标注，不能直接横向排名。若需要比较多个landmark（如3、5、7天），应将其作为预设敏感性分析，并分别构造风险集；不能在验证集上选择表现最好的landmark后作为主结果。

当前数据中部分 `death_28d=1` 病例缺少精确死亡时刻。本次固定28天AUC/Brier的病例身份仍由已知28天结局保证；但C-index和IBS依赖精确事件时刻，因此暂以第28天作为区间末端代理。获得真实院外死亡日期后，应重新计算C-index和IBS。

## 表5-4A当前复算结果

- COX：训练集表观C-index 0.7756；验证集C-index 0.7737；28天AUC 0.8011；28天Brier 0.1404；IBS(0–28天) 0.0918。
- RSF：训练集OOB C-index 0.7712；验证集C-index 0.7954；28天AUC 0.8245；28天Brier 0.1306；IBS(0–28天) 0.0862。
- 训练集两项采用不同估计方式，不能直接排名。共同验证集上，RSF的区分度更高且预测误差更低。
- COX的Schoenfeld残差全局检验P<0.001，提示比例风险假设整体不成立；恒定HR解释应谨慎，可把时间交互或分层模型作为敏感性分析。
