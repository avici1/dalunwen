# 表5-4B：RSFLC与JM统一评价口径

## 1. 比较对象与风险队列

- 任务：第5天landmark动态预测，预测第5天后至第28天的全因死亡。
- 训练/验证划分：沿用现有脚本的 `group=1` 训练、`group=2` 独立验证，不重新随机划分。
- 共同风险队列：仅保留 `T > 5`、0–5天有合格纵向记录、且两模型所需基线/第1天变量完整的患者。
- 两模型必须使用完全相同的训练ID和验证ID；共同队列审计表是比较前的硬性检查。
- 信息截断：任何第5天后的纵向测量都不得进入拟合特征、插补或预测。

## 2. 预测量定义

每个模型必须输出同一评价网格上的个体条件累计风险：

`risk[i,t] = P(T_i <= t | T_i > 5, history_i(0:5))`，其中 `t=5, 5.5, ..., 28`。

风险值应位于 `[0,1]`，并随时间单调不下降。不得把单个28天风险复制到所有时间点后计算IBS。

## 3. 表5-4B五项指标

1. 训练集 C-index：在共同训练风险集中按28天条件风险计算的表观C-index。它只描述拟合，不作为泛化性能主结论，也不与表5-4A中RSF的OOB C-index混同。
2. 验证集 C-index：在共同独立验证风险集中计算，越大越好。
3. 验证集 28天 AUC：使用完整可知的28天死亡二分类结局与模型精确第28天条件风险计算。不得用27.9999天结果替代。
4. 验证集 28天 Brier：`mean((Y_28-risk_28)^2)`；本数据28天死亡身份完整可知，越小越好。
5. 验证集 IBS（5–28天）：逐时点计算IPCW-Brier曲线，用梯形法在5–28天积分，再除以23天；越小越好。

## 4. 删失与边界处理

- 28天死亡状态由 `death_28d` 给出，因此精确28天AUC/Brier按完整二分类端点计算。
- 5–28天中间时点的Brier采用IPCW定义；在当前行政截尾结构下，若没有28天前非事件删失，IPCW权重退化为1。
- 部分 `death_28d=1` 患者缺少精确死亡日期，现有数据只能把事件时刻代理为第28天。这不改变28天AUC/Brier的病例身份，但会影响C-index和IBS；获得准确死亡时刻后必须重算。

## 5. 模型实现约束

- RSFLC必须使用DynForest的 `Y$type="surv"` 生存结局，并直接输出从第5天条件化后的累计发生风险曲线；旧版分类森林只输出28天类别概率，不适合计算IBS。
- 本轮RSFLC按要求临时借用表5-4A RSF参数：`ntree=500, mtry=3, nodesize=10`。该组合不是RSFLC训练集内调参结果，正式定稿前应在动态任务训练集内重新调参。
- JM预测时把患者状态明确设置为第5天仍存活，并输出5–28天 `pred_CIF` 曲线。原GCS/SOFA/CNS三轨迹随机截距+随机斜率版本严重不收敛；简化为三轨迹独立随机截距并延长链后，GCS/CNS关联参数仍未通过Rhat门槛。因此表5-4B最终采用SOFA单轨迹随机截距+随机斜率JM，保留既定25项生存协变量，减少基线风险样条段并启用MALA采样；这些收敛优先的修改均在报告中明确标注。
- JM必须报告MCMC收敛诊断。Rhat不超过1.01较理想；若存在Rhat>1.05，应延长链并复核后再定稿。

## 6. 报告原则

- 主结论只依据共同独立验证集。
- JM与RSFLC可以在动态任务内部比较；不得与静态任务COX/RSF形成四模型总体排名。
- 结果表应同时标注风险队列、landmark、预测窗、训练指标估计方式和RSFLC参数来源。

## 7. 本次重算结果与定稿状态

- 共同队列：训练集3994例（558例事件），验证集1618例（230例事件）。
- RSFLC：训练集表观C-index 0.9698；验证集C-index 0.8205、28天AUC 0.8416、28天Brier 0.0993、IBS(5–28天) 0.0522。验证风险曲线无缺失、无逆向跳变，28天风险范围0.0070–0.5878。
- JM（暂定）：训练集表观C-index 0.7443；验证集C-index 0.7419、28天AUC 0.7565、28天Brier 0.1391、IBS(5–28天) 0.0614。
- JM的最大Rhat为1.1323，共4个参数Rhat>1.05，尚未达到论文最终定稿的收敛标准。其排序指标可用于定位当前实现，但校准指标尤其需要在收敛后复核。
- DynForest 1.2.0原生预测在本数据上因纵向随机效应协方差矩阵奇异而产生近零叶节点风险；本次采用可复现的安全路由函数，按已拟合生存森林分裂规则重新路由，并以岭修正/广义逆处理奇异矩阵。禁止回退到原生近零预测结果。
