# 大论文：静态与动态生存预测：四模型比较研究代码归档

本项目围绕 Cox 比例风险模型、随机生存森林（RSF）、联合模型（JM）和纵向协变量随机生存森林（RSFLC）开展模拟研究与临床实例研究。归档按研究步骤组织，可从下面两个入口阅读。

- **[01_simulation：模拟研究](01_simulation/README.md)**：设计情景 → 生成纵向与生存数据 → 整理模型输入 → 四模型拟合 → C-index、AUC、BS → 汇总与作图。
- **[02_clinical：实例研究](02_clinical/README.md)**：SQL 提取 MIMIC 数据 → 筛选、清洗、插补与分折 → 统一变量配置 → 四模型拟合 → 校准、判别、解释与模型比较 → 图表和报告。
- **[90_history：其他版本](90_history/README.md)**：保留不同实现、调试与探索脚本，按来源清单回溯。
- **[docs：归档说明与来源索引](docs/README.md)**：模拟六维设计、实例变量配置、文件映射和完整性核验。

## 阅读与使用

先读 [模拟设计](docs/SIMULATION_DESIGN.md) 和 [实例变量与版本说明](docs/CLINICAL_DESIGN.md)，再进入对应研究目录。原脚本中的绝对路径、包依赖、对象依赖与运行环境均保留，因此本仓库是研究源码档案，不能视为已完成环境适配的一键运行软件。

实例研究以 `02_clinical/03_models/unified_pipeline/00_config.R` 为导航入口。该套脚本在静态模型之间共享 31 个变量，在动态模型之间共享 28 个固定变量和 3 个轨迹变量。静态与动态任务使用的信息时点不同，不能仅凭变量名称重合就认定四模型评价完全等价。

历史脚本中有直接调整已有指标数值的实现，已保留在 `90_history/manual_metric_adjustment/` 并在 [归档边界](docs/ARCHIVE_NOTES.md) 中说明。这里不展示模型性能结论，也不把历史图表当成此次运行结果。
