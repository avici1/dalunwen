# 第五章完整重算（0831）

## 锁定口径

- 静态任务：时间起点为入院，终点为28天全因死亡；11个固定基线变量加20个纵向指标第1天截面，共31个预测变量。
- 动态任务：landmark固定为第5天，仅纳入第5天仍处于风险集且GCS、SOFA总分、CNS三条轨迹各至少有2次观测者；JM与RSFLC均使用3条轨迹和25个固定协变量。
- RSFLC：使用DynForest的生存结局模式，不再将28天死亡作为普通二分类结局。
- JM：3链、1500次迭代、burn-in 500；正文同时报告Rhat和ESS，不以短链未收敛参数作确定性解释。
- 评价：C-index、28天时间依赖AUC、28天IPCW Brier、IBS；静态IBS积分区间0–28天，动态IBS积分区间5–28天。
- 行政删失边界：无28天死亡者在第28天仍视为已知无事件，28天AUC/BS使用`time >= 28`的对照定义和删失分布左极限。

## 脚本顺序

1. `00_config.R`：变量集合、超参数和统一指标函数。
2. `01_prepare_data.R`：构建静态与landmark队列并输出审计表。
3. `02_static_models.R`：COX、RSF、性能、COX参数、VIMP和最小深度。
4. `02b_static_explain.R`：验证集SHAP、典型患者、PDP、校准和DCA图。
5. `04_jm_unified.R`：JM拟合、分批动态预测、性能、关联参数与MCMC图。
6. `03_rsflc_survival.R`：landmark生存RSFLC、性能、解释和图形。
7. `03b_rsflc_vimp.R`：RSFLC原生OOB VIMP的可断点续跑脚本。
8. `05_combine_results.R`：表5-4B和跨模型汇总图表。

所有随机步骤固定种子2026。模型对象和中间预测均保存，可在中断后复用，避免重复拟合。
