# 历史与替代实现

这里保存主线之外的全部不同源码内容，避免在归档中丢失早期方法、调试或修改过程。

- `simulation/`：模拟的早期生成、拟合、窗口/变量搜索、调试及替代结果处理。
- `clinical/`：临床提取、清洗、建模和解释的其他实现。
- `early_research/`：早期研究、试用与示例脚本，不能仅因位于个人目录就视为正式论文实现。
- `reporting_edits/`：针对论文文档的单次修改和检查脚本。
- `manual_metric_adjustment/`：含直接修改已有指标数值的历史作图脚本，保留过程记录，不作为性能评价入口。

文件前的十位哈希用于区分同名版本。查找原文件位置时，在 [来源清单](../docs/source_manifest.csv) 按原文件名或相对路径搜索；[历史文件索引](../docs/index_90_history.md) 提供逐个链接。

不同版本不自动兼容。本次只归档，不改变研究代码或宣称它们均可直接运行。
